# Microsoft ExecuteIndirect scene assets

`shaders.hlsl` and `compute.hlsl` originate from Microsoft DirectX-Graphics-Samples revision `e5975f9b0744fc5096dd593ed72bf8f5c004164f`; the included MIT license applies. The RHI shaders adapt the command ABI: the original indirect command changes a root CBV and then draws, while this example uses a pure draw command with `StartInstanceLocation` selecting the same scene data through per-instance vertex input. The compute shader applies the same culling equation and writes the draw count on the GPU. Each draw has three vertices, so a triangle list has the same geometry as the original triangle strip.

`frame180.bin` is generated by `tools/examples/indirect-frame.cpp` with MSVC and DirectXMath. Its bytes were checked against the reference application's scene constants captured after the 180th update. The example displays this deterministic animation frame.

DXIL was generated with DXC 1.9.0.5399 using `-T vs_6_0 -E VSMain`, `-T ps_6_0 -E PSMain` and `-T cs_6_0 -E CSMain` respectively.
